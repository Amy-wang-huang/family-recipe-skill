# Family Recipe Skill 🍳

> 基于节气 + 家庭体质的 AI 家庭菜谱生成 Skill
> 第二课作业 · 灵动 AI 编程实战营

## 这是什么

一个让 Claude（或 Cursor 等支持 Skill 的 AI Agent）变成你家"AI 营养师"的 Skill。

**装上之后，你可以这样用它：**

- "下周菜单出一下" → 它按节气 + 你家体质，从菜谱库挑菜，输出一周菜单 + 采购清单
- "最近几天吃了 XX、XX，帮我复盘" → 它按营养维度分析短板 + 给改进建议
- "大暑该吃什么" → 它按节气 + 家庭成员体质给出具体菜式

## 适用场景

家里成员体质差异大、忌口各不相同时特别有用。例如：

- 有人气血不足要补养，有人肝火旺要清淡
- 有人尿酸偏高要控嘌呤，有人对某些食材过敏
- 有孩子要健脾，有老人要控糖

通用菜谱 App 不考虑这些。本 Skill 让 AI 记住你家规则，每次按需调用。

## ⚠️ 使用前必读：填入你的家庭信息

**`references/family-profile.md` 是空白模板**，不包含任何真实个人信息。

装上 Skill 后，**第一步**就是打开这个文件，填入：

- 每位家庭成员的体质、忌口、偏好
- 家庭饮食规则（餐次结构、营养目标）
- 改进目标（用一段时间后再填）

你的家庭数据**只存在你本地的文件里**，不会上传到任何地方。

## Skill 结构

```
family-recipe-skill/
├── README.md              # 你正在看的这个文件
├── skill.md               # 核心定义（Skill 的灵魂）
└── references/            # 引用知识（按需加载，省 Token）
    ├── recipes.md         # 家庭菜谱库（示例 + 你可以扩充）
    ├── family-profile.md  # 家庭成员体质档案（模板，需自填）
    └── seasonal-guide.md  # 二十四节气饮食指引
```

**设计说明**：

- **`skill.md`** 是入口，定义触发场景 + 执行 SOP + 输出格式
- **`references/`** 按需加载：AI 只在需要时读取，避免上下文爆炸（这是 Skill 相比 MCP 的核心优势之一）

## 如何使用

### 方式 1：Claude Code 用户

```bash
# 把本仓库 clone 到本地 Skill 目录
git clone https://github.com/Amy-wang-huang/family-recipe-skill.git \
  ~/.claude/skills/family-recipe-skill
```

然后**编辑 `references/family-profile.md`** 填入你家庭信息，对 Claude 说"出一周菜单"即可触发。

### 方式 2：其他 AI Agent

把仓库下载到本地，填好家庭档案，在 AI Agent 的 Skill 配置中指向本目录。

## 核心特性

✅ **节气感知**：自动识别二十四节气，匹配当令食材
✅ **体质过滤**：每道菜必须符合至少 2 位家人体质（你填的）
✅ **营养复盘**：对近期菜式做 6 维度分析（多样性/蛋白质/粗细比等）
✅ **采购清单**：自动按超市分区归类
✅ **Token 友好**：引用文件按需加载

## 边界声明

- 本 Skill 基于家庭日常饮食管理，**不替代医疗诊断**
- 涉及具体健康问题建议结合体检报告与医生意见

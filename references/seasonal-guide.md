# 节气饮食指引

> 结合阳历+阴历+二十四节气，给出当令食材与烹饪方向。
> 理论参考：陈允斌顺时食养、罗大伦脾胃观、徐文兵节气饮食、曲黎敏养生、董洪斌三伏贴理念。

## 使用规则

1. 每次生成菜谱前，先根据当前日期定位节气（见下表）
2. 按"当令食材"+"烹饪法建议"+"家庭体质过滤"三维匹配
3. 每条建议必须落到**具体菜式/食材/做法**，不堆理论

---

## 春季（立春 ~ 谷雨）

### 养生重点
疏肝理气、健脾升阳、养血柔肝

### 节气细分
- **立春/雨水**（2 月）：升发阳气，宜甜少酸
- **惊蛰/春分**（3 月）：清肝降火，多绿叶菜
- **清明/谷雨**（4 月）：祛湿养脾，芽苗菜旺

### 当令食材（性味归经）
| 食材 | 性味 | 归经 | 推荐做法 |
|------|------|------|---------|
| 韭菜 | 温/辛 | 肝胃 | 韭菜炒鸡蛋 |
| 荠菜 | 凉/甘 | 肝肺 | 荠菜馄饨 |
| 豆芽 | 寒/甘 | 脾大肠 | **焯水后**凉拌（老公少食） |
| 春笋 | 寒/甘 | 肺胃 | 油焖春笋 |
| 香椿 | 温/苦 | 肝胃 | 香椿炒蛋 |
| 菠菜 | 凉/甘 | 肠胃 | **焯水**（老公少食） |
| 草莓 | 凉/甘 | 脾胃 | 餐后水果 |

### 烹饪法
清炒芽苗、凉拌、少油快炒

### 家庭体质匹配（示例方向，按使用者档案调整）
- 肝火偏旺成员 → 春季重点疏肝，韭菜/香椿优先
- 气血不足成员 → 菠菜补铁但需焯水去草酸
- 脾胃弱成员 → 豆芽寒凉，单餐不超 1 样

---

## 夏季（立夏 ~ 大暑）

### 养生重点
清热祛湿、养心安神、生津止渴、健脾化湿

### 节气细分
- **立夏/小满**（5 月）：养心安神，苦味入心
- **芒种/夏至**（6 月）：防暑祛湿，清淡为主
- **小暑/大暑**（7 月）：三伏天，冬病夏治，养长阳气

### 当令食材
| 食材 | 性味 | 归经 | 推荐做法 |
|------|------|------|---------|
| 苦瓜 | 寒/苦 | 心脾 | 凉拌苦瓜（老公） |
| 冬瓜 | 凉/甘 | 肺肠 | 冬瓜薏米汤 |
| 黄瓜 | 凉/甘 | 脾胃 | 凉拌 |
| 番茄 | 凉/酸 | 肝脾 | 番茄牛腩 |
| 丝瓜 | 凉/甘 | 肝胃 | 丝瓜炒蛋 |
| 苋菜 | 凉/甘 | 大肠 | 蒜炒苋菜 |
| 西瓜 | 寒/甘 | 心胃 | 餐后水果（适量） |
| 绿豆 | 凉/甘 | 心胃 | 绿豆汤（小暑起） |
| 生姜 | 温/辛 | 肺脾 | "冬吃萝卜夏吃姜" |

### 烹饪法
蒸、煮、凉拌、少油快炒；**避免油炸、重油重盐**

### 三伏天特殊建议（7 月中-8 月中）
- 贴三伏贴（参考董洪斌理念）
- 饮食温热，**忌冰饮冰食**（伤脾胃）
- 晨起喝姜枣茶（适宜气血不足成员）
- 肝火偏旺成员少吃苦瓜（苦寒伤胃，每周 1-2 次即可）

### 家庭体质匹配（示例方向，按使用者档案调整）
- 气血不足成员 → 三伏忌生冷，姜枣茶补阳
- 肝火偏旺成员 → 苦瓜清热适度，不过量
- 脾胃弱成员 → 绿豆汤少量，不冰镇

## 秋季（立秋 ~ 霜降）

### 养生重点
滋阴润燥、养肺生津、收敛阳气

### 节气细分
- **立秋/处暑**（8 月）：润肺防燥，早睡早起
- **白露/秋分**（9 月）：养阴润肺，少辛多酸
- **寒露/霜降**（10 月）：平补护胃，根茎类登场

### 当令食材
| 食材 | 性味 | 归经 | 推荐做法 |
|------|------|------|---------|
| 梨 | 凉/甘 | 肺胃 | 冰糖炖梨 |
| 百合 | 凉/甘 | 心肺 | 百合银耳羹 |
| 银耳 | 平/甘 | 肺胃 | 银耳羹 |
| 山药 | 平/甘 | 肺脾肾 | 山药排骨汤 |
| 莲藕 | 寒/甘 | 心脾 | 莲藕排骨汤 |
| 白萝卜 | 凉/辛甘 | 肺胃 | 萝卜炖牛腩 |
| 芋头 | 平/甘 | 脾 | 芋头蒸肉 |
| 南瓜 | 温/甘 | 脾胃 | 南瓜小米粥 |
| 苹果 | 凉/甘 | 脾胃 | 餐后水果 |
| 葡萄 | 平/甘酸 | 肺脾 | 餐后水果 |

### 烹饪法
煲汤、炖煮、蒸；**少辛辣**（辣椒、花椒、姜减量）

### 家庭体质匹配（示例方向，按使用者档案调整）
- 气血不足成员 → 山药南瓜小米粥养脾胃
- 肝火偏旺成员（秋燥加重） → 梨/百合/银耳润肺
- 脾胃弱成员 → 山药/南瓜/芋头健脾气

## 冬季（立冬 ~ 大寒）

### 养生重点
补肾藏精、温阳益气、滋阴固本

### 节气细分
- **立冬/小雪**（11 月）：初冬温补，羊肉登场
- **大雪/冬至**（12 月）：进补最佳，黑食养肾
- **小寒/大寒**（1 月）：固本培元，准备迎春

### 当令食材
| 食材 | 性味 | 归经 | 推荐做法 |
|------|------|------|---------|
| 羊肉 | 温/甘 | 脾肾 | 萝卜炖羊肉 |
| 牛肉 | 温/甘 | 脾胃 | 番茄牛腩 |
| 黑米 | 平/甘 | 脾肾 | 黑米饭 |
| 黑豆 | 平/甘 | 脾肾 | 黑豆排骨汤 |
| 黑芝麻 | 平/甘 | 肝肾 | 芝麻糊/芝麻酱 |
| 白萝卜 | 凉/辛甘 | 肺胃 | 萝卜炖羊肉 |
| 大白菜 | 平/甘 | 肠胃 | 白菜豆腐煲 |
| 红薯 | 平/甘 | 脾肾 | 烤红薯/红薯粥 |
| 核桃 | 温/甘 | 肾肺 | 每日 2-3 颗 |
| 板栗 | 温/甘 | 脾肾 | 板栗炖鸡 |

### 烹饪法
炖、煨、煲、烤；**温补为主**，可适量加重油脂

### 冬至特殊建议
- 当日吃饺子（北方习俗）
- 进补黑食（黑米/黑豆/黑芝麻/黑木耳）
- 气血不足成员 → 当归生姜羊肉汤（冬至前后各 1 次）

### 家庭体质匹配（示例方向，按使用者档案调整）
- 气血不足成员 → 羊肉/牛肉/黑食温补
- 肝火偏旺成员（冬季略缓） → 仍忌过燥（少油炸）
- 脾胃弱成员 → 核桃/板栗每日少量，不积食

---

## 跨节气通用规则

1. **不时不食**：非当令食材（如冬天吃西瓜）不推荐
2. **地域考虑**：北方干燥，南方潮湿，按居住地调整
3. **家庭体质优先级**：节气是参考，体质是硬约束（冲突时体质优先）
4. **性味平衡**：一餐中温凉搭配，不过偏
